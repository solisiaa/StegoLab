# Лабораторная 1 — Стеганография LSB (замена 1 младшего бита)

Язык: **Swift**
Запуск на Mac (двойной клик, без Терминала):
```bash
cd 1lab
./scripts/build-app.sh   # соберет и откроет StegoLab.app
# дальше: двойной клик по StegoLab.app в Finder
```

## Что реализовано

### Модуль 1 — Шифрование (вкладка «Шифрование»)
1. Кнопка «Загрузить исходную фотографию» (PNG/JPEG/BMP/TIFF)
2. Переключатель «Текст / Файл»:
   - Текст: поле ввода (печатаешь свой текст)
   - Файл: кнопка «Выбрать файл...» — любой тип (pdf, docx, zip...), сохраняем имя + байты
3. Кнопка «Зашифровать» — встраивает текст или файл в младшие биты, показывает preview
4. Кнопка «Сохранить зашифрованную картинку на диск» — строго **PNG**

### Модуль 2 — Дешифрование (вкладка «Дешифрование»)
1. Кнопка «Открыть исходное изображение» (для сравнения по заданию)
2. Кнопка «Открыть изображение с зашифрованным сообщением»
3. Кнопка «Расшифровать»
4. Поле «Расшифрованное сообщение» + блок «Извлеченный файл» с кнопкой «Сохранить файл на диск...»

## Алгоритм («меняем 1 бит» = LSB + файлы)

Каждый пиксель = 4 байта RGBA. Alpha не трогаем. В каждый байт R, G, B пишем 1 бит нагрузки в младший бит:

```
новый_байт = (старый_байт & 0xFE) | бит_сообщения
```

Изменение яркости ≤ 1/255 — глаз не видит.

Формат v2 (новый, с MAGIC "STG2" для отличия текст/файл):
```
[MAGIC 4 байта] + [режим 1 байт: 0=текст, 1=файл]
текст: [длина 32 бита] + [UTF-8]
файл:  [длина имени 16 бит] + [имя UTF-8] + [длина файла 32 бита] + [байты файла]
```
Старые картинки v1 (только текст без MAGIC) тоже читаются.

Вместимость картинки W×H:
```
capacity_bytes = (W * H * 3 - 72) / 8
```
Пример: 200×200 → ~14991 байт. Файл любого расширения прячем как байты + запоминаем имя, чтобы предложить его при сохранении.

Шифрование (`StegoLSB.embed`):
1. RGBA-пиксели через CGContext
2. Проверка `message.utf8.count <= capacity`
3. Построение массива бит (длина + сообщение)
4. Замена LSB в R,G,B по порядку, alpha пропускается
5. Сборка нового CGImage

Дешифрование (`StegoLSB.extract`):
1. Собрать LSB всех R,G,B
2. Первые 32 бита → длина N
3. Следующие N×8 бит → байты → `String(data:encoding:.utf8)`
4. Если длина больше вместимости / не UTF-8 — ошибка «нет сообщения»

Важно:
- Сохранять только в **PNG/BMP (lossless)**. JPEG с потерями уничтожает младшие биты — сообщение потеряется.
- Оригинал в модуле дешифрования нужен по заданию (для сравнения). Само извлечение идет только из stego-картинки — это правильно для LSB, сравнение попиксельно не требуется.
- Кириллица и эмодзи работают (UTF-8).

## Проверка

```bash
swift build
```

- roundtrip латиница ✅
- roundtrip кириллица + эмодзи ✅
- пустое сообщение ✅
- переполнение → понятная ошибка ✅
